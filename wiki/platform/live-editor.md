## what-it-is
The Live Editor is a component of the OpenHome platform that enables real-time editing and adjustments to be made within the user interface of connected devices, facilitating a more interactive and customizable user experience.

## how-it-works
The Live Editor allows users to make live changes to the configurations and settings of their OpenHome-enabled devices. It integrates with the overall architecture of the OpenHome platform, providing a seamless user interface that responds immediately to input from users. This facilitates immediate feedback and encourages experimentation by users, allowing them to see the effects of their changes in real-time.
