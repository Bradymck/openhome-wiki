### what-it-does
The Trivia ability provides users with various trivia questions and facts across multiple topics, allowing for both entertainment and educational engagement.

### how-to-build
To create a Trivia ability, developers can utilize the following API endpoints:
- **/trivia/question**: Fetches a random trivia question along with multiple-choice answers.
- **/trivia/category**: Allows filtering of questions based on specific categories (e.g., history, science, pop culture).
- **/trivia/score**: Submits user answers and calculates scores based on performance.
